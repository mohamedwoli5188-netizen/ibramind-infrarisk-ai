# IBRAMIND Project Intelligence Showcase

This is a safe, synthetic public demonstration of IBRAMIND's Project Intelligence principles.

It does **not** contain the private production Customer OMNI implementation, Project Truth engine, Engineering Memory service, Scenario Engine, proprietary commercial rules, tenant architecture, or privileged Founder controls.

## What it demonstrates

A simplified read-only intelligence surface over governed project records:

```
Project records
    ↓
Truth states + evidence references
    ↓
Digital Thread relationships
    ↓
Change-impact summary
    ↓
Validated engineering memory
    ↓
Non-authoritative scenario analysis
    ↓
Human review / decision
```

The demo keeps authoritative records and hypothetical scenarios separate.

## Run

```bash
python showcases/project_intelligence/demo.py
```

The output includes:

- project truth-state counts
- evidence coverage
- Digital Thread relationship counts
- validated engineering memory
- downstream change-impact references
- one what-if commercial scenario
- an explicit `authoritative: false` scenario boundary

## Safety boundary

This public showcase intentionally excludes:

- production database schemas
- real customer/project data
- private authorization and tenant-isolation internals
- production Evidence Passport implementation
- private Digital Thread graph internals
- private Engineering Memory lifecycle implementation
- private Scenario Engine implementation
- organization-specific commercial rules
- production deployment details and credentials

The private IBRAMIND platform remains the authoritative product.

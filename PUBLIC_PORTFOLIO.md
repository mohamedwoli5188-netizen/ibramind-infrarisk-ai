# IBRAMIND Public Portfolio

**Engineering intelligence for connected, governed, evidence-based infrastructure delivery.**

This page is the public index for IBRAMIND technical showcases.

IBRAMIND's production platform remains private. The repositories and demos linked here use synthetic/open data and expose only bounded public demonstrations of selected capabilities.

## What IBRAMIND is

IBRAMIND is being developed as an Engineering Intelligence Operating System connecting engineering, BIM, commercial, project, field, document, procurement, risk, and governance workflows.

A simplified public view of the platform direction is:

```
Drawings / BIM / Documents
          ↓
Engineering Graph / Digital Thread
          ↓
QTO → BOQ → Measurement → IPC
          ↓
Variation / Claim / Procurement / Cost
          ↓
Commercial & Project Intelligence
          ↓
Evidence → Truth State → Change Impact
          ↓
Connected Search → Engineering Memory → Scenarios
          ↓
Human Review / Governed Action
```

## What is deliberately not public

The public portfolio does not expose:

- Customer OMNI production source
- Founder OMNI privileged control plane
- customer or tenant data
- production authentication/authorization internals
- proprietary engineering/commercial rules
- private Project Truth implementation
- production Digital Thread graph internals
- private Evidence Passport persistence
- private Engineering Memory or Scenario Engine internals
- private connectors and enterprise integrations
- production infrastructure or secrets
